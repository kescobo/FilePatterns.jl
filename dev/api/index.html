FilePatterns — Module
FilePatterns

Find files whose names match a regex or a template, and return the matches as a Tables.jl row table of NamedTuples holding each file's name, its directory, and the values of the named captures.

See filesearch, Pattern, MissingMatchesError and DuplicateMatchesError.

source
FilePatterns.filesearch — Function
filesearch(pattern::Union{Regex, Pattern}, dir::AbstractString = ".";
           recursive = false, strict = true, distinct = true,
           select = nothing, require = nothing)

Find the files in dir whose names match pattern and return one NamedTuple per file, sorted by (directory, filename).

Each result has the fields filename (the file's base name), directory (the directory containing it), and then one String field per named capture group of pattern, in the order the groups appear. A group that did not take part in the match (such as an optional (?<lane>_L\d+)?) is "", which cannot be told apart from a group that matched the empty string. Unnamed groups are ignored. The full path of a result m is joinpath(m.directory, m.filename).

The result is a Tables.jl row table, so DataFrame(filesearch(...)) works.

Arguments

  • pattern: a Regex with named capture groups, or a Pattern. It is matched against each file's base name only.
  • dir: the directory to search. directory values are built from it exactly as given, so a relative dir yields relative directories.
  • recursive: also search subdirectories. Symlinked directories are not followed. Symlinks to files are matched; broken symlinks are skipped.
  • strict: when true, pattern must match the whole file name. When false, a match anywhere in the name is enough.
  • distinct: when true, throw DuplicateMatchesError if two or more files have the same values for every named capture, wherever they are. When false, return every match and leave telling them apart to the caller. Patterns without named captures are never checked.
  • select: keep only matches whose captures take one of the given value combinations.
  • require: throw MissingMatchesError unless every expected value combination is matched. It never removes results.

select and require specs

Both accept either form:

  • A NamedTuple or AbstractDict{Symbol} mapping capture names to collections of values, meaning every combination of those values (their Cartesian product). A string or other scalar counts as a single value. A NamedTuple of vectors is always read this way; wrap it in Tables.rowtable to pass rows.
  • Any other Tables.jl table, such as a DataFrame or a vector of NamedTuples, whose rows are the combinations and whose column names are capture names.

Values are compared as strings after conversion with string, so R = 1:2 matches captures "1" and "2". Captures not named in a spec are unconstrained.

require checks each group of matches separately, where a group is one combination of the captures not named in the spec. With captures sample and R, require = (R = 1:2,) fails if some sample has an R = "1" file but no R = "2" file. When nothing matches, every expected combination is missing.

select is applied first, then the distinct check, then require, so files removed by select cannot count as duplicates.

Errors

  • ArgumentError if dir is not an existing directory, if pattern has a capture named filename or directory, or if a select or require key is not a capture name.
  • DuplicateMatchesError if distinct is true and files share all capture values.
  • MissingMatchesError if require is not satisfied.

Examples

With a directory fastqs holding R1 and R2 files for samples A0001 and A0002:

julia> filesearch(r"(?<sample>[A-Z0-9]+)_L001_R(?<R>1|2)\.fastq\.gz", "fastqs"; select = (sample = "A0001",))
2-element Vector{@NamedTuple{filename::String, directory::String, sample::String, R::String}}:
 (filename = "A0001_L001_R1.fastq.gz", directory = "fastqs", sample = "A0001", R = "1")
 (filename = "A0001_L001_R2.fastq.gz", directory = "fastqs", sample = "A0001", R = "2")

julia> pat = Pattern("<sample>_L001_R<R>.fastq.gz"; R = r"1|2");

julia> length(filesearch(pat, "fastqs"; require = (sample = ["A0001", "A0002"], R = [1, 2])))
4

FilePatterns.Pattern — Type
Pattern(template::AbstractString; captures...)

A file name pattern written as literal text with named captures in angle brackets, such as "<sample>_L001_R<R>.fastq.gz". Pass a Pattern to filesearch in place of a Regex.

Template syntax

  • <name> is a named capture. name must match [A-Za-z_][A-Za-z0-9_]*, must not repeat, and must not be filename or directory.
  • << is a literal <. A > outside a capture is literal.
  • All other text is literal, including regex metacharacters: . matches only a dot.

Capture regexes

By default a capture matches [^/]+? (one or more characters, lazily). A keyword argument named after a capture replaces that default with a Regex or a regex source string. A capture regex may contain unnamed groups but not named ones, and may not carry flags such as r"..."i.

Errors

Throws ArgumentError for an empty template, an unclosed <, an invalid, duplicate or reserved capture name, a keyword that names no capture, or a capture regex with named groups or flags. Messages for template errors give the character position of the problem.

Examples

julia> pat = Pattern("<sample>_L001_R<R>.fastq.gz"; R = r"1|2")
Pattern("<sample>_L001_R<R>.fastq.gz"; R = r"1|2")

julia> pat.regex
r"(?<sample>[^/]+?)_L001_R(?<R>1|2)\.fastq\.gz"

julia> first(filesearch(pat, "fastqs"))
(filename = "A0001_L001_R1.fastq.gz", directory = "fastqs", sample = "A0001", R = "1")

FilePatterns.MissingMatchesError — Type
MissingMatchesError <: Exception

Thrown by filesearch when the require option expects combinations of capture values that no matched file provides.

Fields

  • missing::Vector{<:NamedTuple}: one entry per missing combination. Each entry holds the values of the captures that define its group (the captures not named in require), followed by the expected values of the captures named in require. When nothing matched at all, entries hold only the latter.
  • pattern::Union{Regex, Pattern}: the pattern that was searched for.
  • directory::String: the directory that was searched.

Examples

With a directory reads holding S1_R1.fastq.gz, S1_R2.fastq.gz and S2_R1.fastq.gz:

julia> err = try
           filesearch(r"(?<sample>\w+)_R(?<R>\d)\.fastq\.gz", "reads"; require = (R = 1:2,))
       catch e
           e
       end;

julia> err.missing
1-element Vector{@NamedTuple{sample::String, R::String}}:
 (sample = "S2", R = "2")

FilePatterns.DuplicateMatchesError — Type
DuplicateMatchesError <: Exception

Thrown by filesearch when two or more matched files have the same values for every named capture, for example sample1_R1.fastq.gz and mod_sample1_R1.fastq.gz with strict = false, or files with the same name in different directories with recursive = true. Pass distinct = false to filesearch to return every match instead.

Fields

  • duplicates::Vector{<:Pair{<:NamedTuple, Vector{String}}}: one entry per shared combination of capture values, mapping it to the paths of the files that have it, sorted by the capture values.
  • pattern::Union{Regex, Pattern}: the pattern that was searched for.
  • directory::String: the directory that was searched.

Examples

With a directory mixed holding S1_L001_R1.fastq.gz, S1_R1.fastq.gz and S1_R2.fastq.gz:

julia> err = try
           filesearch(r"(?<sample>S\d+)(?:_L\d+)?_R(?<R>\d)\.fastq\.gz", "mixed")
       catch e
           e
       end;

julia> err.duplicates
1-element Vector{Pair{@NamedTuple{sample::String, R::String}, Vector{String}}}:
 (sample = "S1", R = "1") => ["mixed/S1_L001_R1.fastq.gz", "mixed/S1_R1.fastq.gz"]
